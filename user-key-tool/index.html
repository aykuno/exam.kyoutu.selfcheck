ユーザー登録データで採点する

自分で作った正答データを使って、模試・プリント・自作問題などを採点するページです。

まず最初に

この機能は、通常の共通テスト・センター試験採点とは別です。通常ページはサイト側に登録済みの正答データで採点しますが、ここでは利用者が自分で登録した正答データで採点します。

使う順番は、正答データを作る → 保存する → 採点画面で選ぶ → 自分の解答を入力する、です。

JSONは、作成した正答データをバックアップしたり、別のスマホ・PCへ移したりするためのファイルです。普段は意識しなくて構いません。
最初に使う

正答データを作る

テスト名、科目、解答番号、正解、配点を登録します。学校プリントや模試など、公式登録されていない問題を採点したいときはここから始めます。

作成画面を開く
保存後に使う

作成済みデータで採点する

保存した正答データを選び、自分の解答を入力して採点します。点数・正誤一覧を確認し、PDFとして保存できます。

採点画面を開く

基本の流れ

1正答データを作る作成画面で、年度・試験名・科目・満点を入力し、大問構成から解答番号を作ります。
2正解と配点を入れる各解答番号の正解を入力し、配点を確認します。まとめて完答・順不同完答が必要な問題は配点設定で調整します。
3ユーザー登録データとして保存する保存すると、同じブラウザ内の「登録済みユーザーデータ」に残ります。
4採点画面でデータを選ぶ保存済みデータを選び、自分の解答を入力して採点します。
5必要ならPDF・JSONで保存する採点結果はPDF保存できます。正答データを別端末へ移す場合はJSON保存を使います。

どちらを使えばよいか

  • 共通テスト・センター試験の本試験や追試験を採点したい通常の採点サイトを使います。登録済みの公式データで採点します。
  • 学校のプリント・模試・自作問題を採点したいこのページを使います。自分で正答データを作ってから採点します。
  • 別端末でも同じ正答データを使いたい作成画面でJSON保存し、別端末の採点画面でJSON読み込みを行います。

このツールでできること

  • 正答データの作成解答番号、正解、配点、大問構成を登録できます。
  • 保存済みデータの管理作成済みデータの編集、複製、削除、JSON保存ができます。更新順・五十音順で並び替えられます。
  • 自分の解答の保存採点画面で入力した自分の解答を保存・読み込みできます。途中まで入力した解答を後で続けられます。
  • PDF保存採点結果をPDFで保存できます。

保存について

作成した正答データと自分の解答は、このブラウザ内に保存されます。サイト管理者が保存内容を見ることはできません。

ブラウザのデータを削除した場合、別の端末を使った場合、別のブラウザで開いた場合は、保存済みデータは自動では表示されません。必要なデータはJSONファイルとしてバックアップしてください。
