ユーザー登録データ ツール

正答データの作成と、作成済みデータによる採点ができます。

① 正答データ作成

正答データを作成する

年度・試験名・科目を入力し、正答・配点・問題番号を登録します。作成済みデータの管理やJSON書き出しもできます。

作成画面を開く
② 採点

作成済みデータで採点する

作成済みの正答データを選び、自分の解答を入力して採点します。JSONファイルの読み込みもできます。

採点画面を開く

使う順番

1正答データを作る試験・科目・正答・配点・問題番号を登録して保存します。
2採点画面でデータを選ぶ保存済みデータを選択します。JSONファイルから読み込むこともできます。
3自分の解答を入力して採点する入力カードに解答を入れ、採点ボタンで照合します。採点結果はPDF出力できます。
作成画面正答・配点登録 JSON読み込み採点画面内で実行 通常の採点サイト本試験・追試験など
