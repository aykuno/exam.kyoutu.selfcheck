ユーザー登録データ ツール

自分で作った正答データを保存し、そのデータを使って採点できます。

① 正答データ作成

正答データを作成する

年度・試験名・科目を入力し、解答番号、正答、配点、問題番号を登録します。作成したデータは同じブラウザ内に保存されます。

作成画面を開く
② 採点

作成済みデータで採点する

保存済みの正答データを選び、自分の解答を入力して採点します。結果は設問別に確認でき、PDF出力もできます。

採点画面を開く

使う順番

1正答データを作る大問構成を入力し、解答番号を作成します。その後、各番号の正答を入力します。
2配点を設定して保存する各番号の配点を確認します。まとめて完答や順不同完答が必要な問題は、配点設定で調整できます。
3採点画面でデータを選ぶ保存済みデータを選択します。別端末で作ったJSONファイルを読み込むこともできます。
4自分の解答を入力して採点する解答カードに自分の解答を入力し、「採点する」で点数・正誤・未入力を確認します。

このツールでできること

  • 正答データの作成模試・学校内テスト・自作問題など、公式データにない試験の正答データを作れます。
  • 保存済みデータの管理作成済みデータの編集、複製、削除、JSON保存ができます。更新順・五十音順で並び替えられます。
  • 自分の解答の保存採点画面で入力した自分の解答も保存・読み込みできます。続きから入力するときに使えます。
  • JSONでの移動作成した正答データはJSONファイルとして保存できます。別端末や別ブラウザへ移すときはJSONを使います。

保存について

作成した正答データと自分の解答は、このブラウザ内に保存されます。別のスマホ・別のPC・別ブラウザでは自動共有されません。

別端末で使う場合は、作成画面のJSON保存でファイルを書き出し、使いたい端末でJSON読み込みを行ってください。
