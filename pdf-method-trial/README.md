# PDF保存方式の独立検証

バージョン：v1.0.0  
最終更新：2026/09/12 23:22（日本時間）

引き継ぎ資料「PDF保存の仕組み」にある方式を、単体HTMLで試すための実装です。

SVG文字列 → Canvas描画 → JPEG変換 → PDFバイナリ生成 → data URIのダウンロードリンク、の順で処理します。PDF生成後に利用者がリンクを押して保存します。

## 使い方

1. このフォルダの `index.html` をブラウザーで開きます。GitHub Pagesではリポジトリの公開URLに `pdf-method-trial/` を付けたページです。
2. 「資料の方式でPDFを生成」を押します。
3. 生成完了後に表示される「PDFをダウンロード」を押します。
4. 保存した `pdf-method-trial-result.pdf` を開き、2ページとも文字・表・ページ番号を確認します。

資料のSafari向け操作案内は、リンクの長押し →「リンクをダウンロード」です。機種やOSで表示されるメニューは異なります。
