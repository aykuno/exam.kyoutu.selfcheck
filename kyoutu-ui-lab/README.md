# 共通テスト・センター試験 自動採点 UI検証版

メインサイト本体を変更せず、次期UIを実データで確認するための専用ページです。

## 収録範囲

- 2025年度 共通テスト本試験（メインサイト収録の全38科目）
- 2026年度 第2回 河合全統共通テスト模試（全21科目）
- 大問構成、配点、複数解答、順不同、部分点、条件付き正解、選択問題を反映
- 2025年度本試験は、収録済みの平均点・正答率も表示

## 検証対象

- スマートフォン優先の3ステップ画面
- 登録済み試験は、年度・試験・科目を決めてから番号入力／答案撮影を選択
- 登録済み試験の写真採点は答案だけを読み取り、収録済み正解・配点で自動採点
- 「自分の持つ解答と照合する」は最初の試験選択画面から独立して開始
- スマホ型10キー（`1 2 3 / 4 5 6 / 7 8 9 / － 0 消去`）
- 必要な科目だけ数字の後段に英字キーを表示
- 未登録試験では答案用紙と解答・配点一覧を撮影して写真同士で採点
- 初回撮影は説明画面から直接カメラを開き、重複する撮影開始画面を表示しない
- 写真採点も共通のヘッダー・3ステップ表示・戻る操作を使用（別ページ遷移なし）
- 入力内容は端末内へ自動保存（ホーム画面の「入力を再開」は表示しない）
- 試験・科目選択へ戻るボタン
- 現行メインと同じ採点規則および全問正誤の7列構成
- 番号入力・答案撮影・写真同士の照合で、同一の採点結果画面と同一のA4 PDFデザインを使用
- 現行 `pdf_export_v160.js` を使用したA4 PDFとSafari向けdata URI保存
- 画面・PDFの全問正誤では、判定記号を大きく表示
- PDFの判定記号と得点を同じ行中央へ揃える
- ホーム画面は「登録済みの試験で採点」→「登録のない試験はこちら」の順で表示
- 未登録試験の撮影順を「答案用紙 → 解答・配点一覧」と明記
- 「国語・通常型」は、国語などで使う1〜60の番号が並ぶ片面式答案用紙として説明

## 変更範囲

このフォルダ内のファイルだけで動作します。ルートのメインサイト、正解データ、統計データ、PDF出力コードは変更しません。

## 写真採点の更新（v20261004-universal1／2026-10-04 JST）

- 写真採点を全科目で既存のFirebase AI Logic／Google Geminiへ統一。モデル・課金設定は変更していません。
- 用紙の座標・列数・1〜60番・表裏2面の前提を外し、印刷された欄番号・カナ・英字・負号を照合します。
- 登録済みの正解はAIへ送信せず、欄名だけを渡し、従来の正誤・配点・順不同・部分点・選択規則で採点します。
- 1枚から読取確認へ進めます。答案・解答の各写真は最大8枚まとめて選択でき、写真追加と同じ写真の再試行に対応します。
- 判読不能・未撮影の欄は「要確認」とし、未記入とは区別。手入力で直した答案は再試行・写真追加でも維持します。
- 写真は作業中のメモリだけに保持します。氏名・受験番号等を隠して撮影する案内を表示し、選択した画像全体がGoogleへ送信されることを明示しています。
- 保存対象は読取結果と確認内容。従来の保存済み答案を復元できます。
- 実行環境の起動エラーにより実機ブラウザ・実物写真での精度試験は未実施です。JavaScript構文、読取応答の検証、DOMを模した操作試験で、1枚読取・追加・再試行・保存復元・古い応答の破棄・英字・負号・順不同の部分点を確認しました。
- 自由記述の内容評価や、すべての用紙の読取精度を保証するものではありません。ラベルの不明な欄は手入力または拡大写真で確認が必要です。

## 複数欄・採点規則の更新（v20261004-universal2／2026-10-04 JST）

- 答案・正解の連結値を、印刷された欄数が一致する場合だけ分解します。`−12`と3欄、`10`と1欄を区別します。
- まとめて完答、順不同、各欄の部分点、指定解答の部分点、別解、条件付き正解、全員得点、選択大問を写真由来の採点データへ取り込みます。
- 同じ欄名が複数の大問にある場合も、条件付き正解を同じ大問内で照合します。科目指定・受験番号等の欄は答案項目から除くよう指示します。
- 読取確認画面で合計配点・採点方法・1つ正解の点を確認、修正できます。欄数や部分点が不正な編集状態では採点を止めます。
- 正解写真の不足を表示し、未登録試験は読めた項目の実得点を使用します。未確認の範囲を満点換算しません。
- 既存のFirebaseプロジェクト・モデル・App Check・課金設定は変更しません。検証はGoogle APIを呼ばず、登録済みの採点規則との比較とモバイルブラウザの操作で実施します。
- 任意の実物写真での認識精度は別の確認事項です。AIの推測だけで配点や採点規則を補いません。

### 変更ファイル

- `photo/answer-format.js`（新規）：欄名・連結値・採点規則の正規化。
- `photo/ai-reader.js`：複数欄・部分点・条件付き正解等の読取指示と応答形式。
- `photo/grader.js`：大問内の依存解答照合、選択指定、不足範囲の扱い。
- `photo/universal-reader.js`：写真の追加照合、採点規則の保持・確認・修正。
- `photo/style.css`：スマホの採点規則編集表。
- `index.html`：正規化スクリプトの読み込みとキャッシュ更新。
- `photo/tests/format-grader.test.cjs`（新規）：形式28ケースと既存59科目の3,838件比較。
- `README.md`：更新内容と検証範囲。

既存の解答・統計JSON、番号入力の採点規則、Firebase設定、ルートのindex.html、PDF出力と公開設定は変更していません。登録済み科目の得点判定は従来の番号入力と一致します。写真採点では未入力数を、複数欄の一部が未記入の場合も含めて表示します。

検証：形式28ケース、2025年度本試験38科目と2026年度河合模試21科目で3,838件の得点比較、430px幅のChromiumで写真選択・連結解答・合計配点と部分点の編集・採点・不正編集の阻止を確認。ブラウザ試験のAI応答は既知の値に固定しており、実物写真の認識精度試験ではありません。Google API呼び出しは0回です。検証用ワークフローと画面記録は `audit/photo-rules-20261004` ブランチに保存しています。
