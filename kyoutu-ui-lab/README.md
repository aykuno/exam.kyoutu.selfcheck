# 共通テスト・センター試験 自動採点 UI検証版

メインサイト本体を変更せず、次期UIを実データで確認するための専用ページです。

## 収録範囲

- 2025年度 共通テスト本試験（メインサイト収録の全38科目）
- 2026年度 第2回 河合全統共通テスト模試（全21科目）
- 大問構成、配点、複数解答、順不同、部分点、条件付き正解、選択問題を反映
- 2025年度本試験は、収録済みの平均点・正答率も表示

## 検証対象

- スマートフォン優先の3ステップ画面
- 登録済み試験は、年度・試験・科目を決めてから番号入力／答案撮影を選択
- 登録済み試験の写真採点は答案だけを読み取り、収録済み正解・配点で自動採点
- 「自分の持つ解答と照合する」は最初の試験選択画面から独立して開始
- スマホ型10キー（`1 2 3 / 4 5 6 / 7 8 9 / － 0 消去`）
- 必要な科目だけ数字の後段に英字キーを表示
- 未登録試験では答案用紙と解答・配点一覧を撮影して写真同士で採点
- 初回撮影は説明画面から直接カメラを開き、重複する撮影開始画面を表示しない
- 写真採点も共通のヘッダー・3ステップ表示・戻る操作を使用（別ページ遷移なし）
- 端末内自動保存と「前回の続きから」
- 試験・科目選択へ戻るボタン
- 現行メインと同じ採点規則および全問正誤の7列構成
- 現行 `pdf_export_v160.js` を使用したA4 PDFとSafari向けdata URI保存
- 画面・PDFの全問正誤では、判定記号を大きく表示

## 変更範囲

このフォルダ内のファイルだけで動作します。ルートのメインサイト、正解データ、統計データ、PDF出力コードは変更しません。
