# 共通テスト・センター試験 自動採点 UI検証版

メインサイト本体を変更せず、次期UIを実データで確認するための専用ページです。

## 収録範囲

- 2025年度 共通テスト本試験（メインサイト収録の全38科目）
- 2026年度 第2回 河合全統共通テスト模試（全21科目）
- 大問構成、配点、複数解答、順不同、部分点、条件付き正解、選択問題を反映
- 2025年度本試験は、収録済みの平均点・正答率も表示

## 検証対象

- スマートフォン優先の3ステップ画面
- 電卓型10キー（`7 8 9 / 4 5 6 / 1 2 3 / － 0 消去`）
- 必要な科目だけ数字の後段に英字キーを表示
- 端末内自動保存と「前回の続きから」
- 試験・科目選択へ戻るボタン
- 現行メインと同じ採点規則および全問正誤の7列構成
- 現行 `pdf_export_v160.js` を使用したA4 PDFとSafari向けdata URI保存

## 変更範囲

このフォルダ内の `index.html`、`style.css`、`app.js`、`README.md` のみで動作します。ルートのメインサイト、正解データ、統計データ、PDF出力コードは読み取り専用で参照し、変更しません。
