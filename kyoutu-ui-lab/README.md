# 共通テスト・センター試験 自動採点 UI検証版

メインサイトに影響を与えず、画面構成と操作性を確認するための独立した静的サイトです。

## 確認できる内容

- 前回の続きから再開する画面
- 年度・試験・科目の選択
- 国語、数学I・A、英語リーディング、情報I、物理、化学、地理の入力画面
- 科目別のキー切り替え
  - 数学は `－` を `0` より前に表示
  - 情報Iは数字の後ろに `A`、`B`、`C` を表示
- スマートフォン用の画面下固定キー
- 端末内自動保存
- 未入力確認
- 採点結果、大問別得点、レーダーチャート、誤答一覧、全問正誤
- 外部ライブラリを使わないPDF生成とSafari向けダウンロードリンク

## 注意

- 正解、配点、平均点はUI確認用のサンプルです。
- メインサイトの正解データ、保存データ、採点処理には接続しません。
- GitHub Pagesではリポジトリ直下の `index.html` をそのまま公開できます。
