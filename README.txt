手動解答登録ビルダー（分離版）

目的:
- 共テ・センター自動採点サイト本体とは混ぜずに、ユーザー登録用の正解データを作成・保存・採点テストするための単体ページです。

含まれるファイル:
- user-key-builder.html
- user-key-builder.css
- user-key-builder.js
- README.txt

重要:
- index.html は含めていません。
- pdf_export_v160.js は含めていません。
- answer_keys_verified.json / statistics_final.json 等の既存JSONは含めていません。
- GitHub / 本番サイトへの反映は行っていません。
- このZIPは新規ファイルのみです。

保存先 localStorage:
- ユーザー登録正解データ: ct-marker-user-answer-keys-v1
- ユーザー解答保存: ct-marker-user-answers-v1

使い方:
1. user-key-builder.html をブラウザで開く。
2. 年度・試験名・科目名・満点を入力する。
3. 設問一覧に id / 正解 / 配点 / 大問 / 形式を入力する。
4. 「検査」で不備を確認する。
5. 「保存」で localStorage に保存する。
6. 「採点画面を作る」で入力カードを出し、「採点する」で動作確認する。
7. 必要なら「JSON出力」または「JSONファイル保存」でエクスポートする。

正解欄の書き方:
- 通常: 2
- 複数枠: 1,2,3
- 順不同: 形式を「順不同」にして 2,4
- 複数許容: 形式を「複数許容」にして 1|3,2|4
- 部分点: 形式を「部分点」にして、部分点欄へ1枠あたりの点を入力

本番統合について:
- このページは単体で動く確認用です。
- 本番 index.html へのリンク追加や採点本体との接続は未実施です。
- 統合する場合も、別途承認を得てから最小差分で進める前提です。
